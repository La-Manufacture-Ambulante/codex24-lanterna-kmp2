# Code of Conduct

## Our Standards
- Be respectful and constructive.
- Assume good intent and focus on technical outcomes.
- Avoid harassment, discrimination, and personal attacks.

## Scope
This code of conduct applies to repository discussions, issues, pull requests, and related project communication channels.

## Reporting
If you experience or witness unacceptable behavior, contact repository maintainers privately with relevant context.

Maintainers are expected to review reports promptly and take appropriate action.
