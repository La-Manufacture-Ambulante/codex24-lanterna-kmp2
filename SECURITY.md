# Security Policy

## Reporting a Vulnerability
Please do not open public issues for undisclosed vulnerabilities.

Report security concerns privately to the maintainers of this repository through GitHub security reporting features if available for this repo, or by contacting the repository owners directly.

Include:
- affected module(s),
- reproduction details,
- expected vs actual behavior,
- impact assessment.

We will acknowledge reports and work on a fix as quickly as possible.
